# Исследование поведения игрока в Unity

Учебный исследовательский репозиторий по лабораторным работам №3–4 и №11–12 курса «Информационные системы и технологии в научных исследованиях» (магистратура, геймдизайн).

## Исследовательский вопрос

Как распределено время до попадания по цели в простой Unity-сцене и что можно узнать из событийной телеметрии одного запуска?

Гипотеза для проверки в расширенном эксперименте: отдельные долгие реакции увеличивают среднее время сильнее, чем медиану. На имеющейся одной сессии можно проверить только описательную часть, а не обобщение на игроков.

## Данные и происхождение

В `data/raw/simulation_log_1795012796.csv` лежит **исходный CSV реального запуска Unity** 18.11.2026: один обезличенный игрок, одна сессия, 123 события (62 `hit`, 40 `miss`, 21 `move`). Это не синтетический датасет. Исходный файл сохраняется без изменений.

В других учебных лабораторных применялись синтетические выборки. Они здесь не смешиваются с настоящим Unity-логом.

## Запуск анализа

Требования: Python **3.10+**, сторонние пакеты не нужны. Устанавливать Unity для повторного анализа CSV не требуется.

```bash
python scripts/analyze.py
python -m unittest discover -s tests
```

Итоги сохраняются в `results/summary.json`, потенциальные выбросы — в `data/processed/outliers.csv`. Файлы `data/processed` можно регенерировать из исходного CSV.

## Структура

- `unity/PlayerExperiment.cs` — скрипт сцены и логирования;
- `data/raw/` — исходный CSV без редактирования;
- `data/processed/` — производные сводки и выбросы;
- `scripts/` — воспроизводимая обработка;
- `tests/` — проверки формул и результатов;
- `results/` — показатели и интерпретация;
- `docs/` — словарь данных, правила и экспорт материалов для Wiki;
- `reports/` — исследовательский и итоговый отчёты о совместной работе.

Ни одна метрика из этой сессии не позволяет оценить Retention или эффективность A/B-теста. Здесь нет данных других игроков, а независимое экспертное ревью другим участником не заявляется. Все источники и используемый код доступны в репозитории.
