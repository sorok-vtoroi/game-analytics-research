# Словарь данных Unity

Источник: реальный запуск демонстрационной сцены Unity 18 ноября 2026 года. Один участник, одна сессия. Файл `data/raw/simulation_log_1795012796.csv` не изменяется.

| Поле | Тип | Значение |
|---|---|---|
| player_id | целое | обезличенный идентификатор |
| session_id | целое | идентификатор запуска, основан на Unix-времени |
| timestamp | ISO 8601, UTC | время события |
| event_type | строка | `hit`, `miss`, `move` |
| object_id | целое | 1 для цели, 0 для остальных событий |
| x_position | число | координата игрока X |
| y_position | число | координата игрока по Z-системе Unity (историческое название CSV) |
| reaction_time | число / пусто | секунды от появления цели до попадания, только для `hit` |
| score | целое | 1 за попадание, 0 иначе |

Пустое `reaction_time` в строках `move` и `miss` — ожидаемое значение, а не ошибка. В анализ реакции включаются только попадания.

## Ограничения

- Данных одного пользователя недостаточно для обобщения на игроков в целом.
- Записанные `move` — периодическая выборка движений, не непрерывная траектория.
- Из CSV нельзя вычислить Retention D1/D7 или эффект A/B-теста.
- Данные одной Unity-сессии **не являются синтетическими**; синтетические выборки других лабораторных с ними не смешаны.
